## 自动回归与维护边界

候选安装及正式安装均通过 12 项 Node 测试：

- 审批：当前会话 API、nonce、审批人、重放、拒绝、并发请求、取消、发送失败与卸载清理。
- 入口：私人白名单、群禁用、空白名单拒绝。
- 文件：工作区内文件允许，Windows junction 越界拒绝，禁用群和未知收件人拒绝。发送器使用本地桩，没有实际外发测试文件。
- 提问：发送期间取消及时结束，随机 nonce、点击用户和选项整数校验，旧按钮失效，文本答案可用，旧发送失败不删除新问题。
- 维护：升级准备保留自定义设置，显式空白名单不会被重新填入；损坏和不完整备份被拒绝。

另外实际验证：修改候选 package.json 后部署检查拒绝，恢复原候选后检查通过；维护持锁时权限编辑被 Windows 文件锁拒绝。新备份的完整性验证通过。

这轮修复通过固定版本 `patchedDependencies` 安装，可由上游文件快照、维护源码和生成脚本重建。本体发行文件保持未修改。

## 未覆盖与后续功能

- 提问卡按钮目前为本地回归，手机端实点的是权限审批卡。文件传输仅测试路径与收件人逻辑，未做真实图片、语音或文件下载验收。
- 未人为破坏正式运行实例来触发自动回滚；恢复链路使用同版本备份演练，损坏备份拒绝使用隔离测试文件验证。
- 未实测 Windows 注销、重启、休眠及断网恢复；当前没有新增登录自启和外部守护进程。
- 未做搜索引擎、Bilibili 字幕或图像理解的完整功能验收。
- 优先后续补充：登录自启及掉线恢复、重启后的 QQ 结果通知、备份保留周期。开放其他用户前需增加真实管理员/只读角色隔离，当前白名单成员共享同一能力。

`Doctor` 与 `Result` 已补充到维护入口，支持 QQ Agent 查询健康状态和最近一次维护结果。
